Football Analytics Data Warehouse

A Python server builds a star schema in SQLite from a messy match feed, answers OLAP queries in SQL, and mines the warehouse with k-means and Apriori.

Introduction

Topic: Design and Implementation of a Football Analytics Data Warehouse.

Football produces a huge amount of data every week: scores, goals, shots, cards, players and standings. In raw form this data comes from different sources, is often inconsistent, and is hard to analyse. This project builds a complete system that collects such data, cleans it, stores it in a data warehouse, and then turns it into useful insight through OLAP reporting and data mining. It also connects to a live football feed so the same ideas can be seen on real, current data with team badges and footballer photos.

What is it?

It is a working web application written in Python. A Python server builds a SQLite database organised as a star schema, loads it with match data, answers analytical questions in SQL, and shows everything in this website. The goal is to show how a data warehouse supports decision making in sports analytics.

Raw match feed→ETL (Python)→Warehouse (SQLite star schema)→OLAP (SQL)+Data mining→Live football feed

Key concepts

Data warehouse

A central database designed for analysis rather than daily transactions. It keeps clean, historical data from many sources in one place.

Star schema

The warehouse layout: fact tables hold the numbers (goals, points) and dimension tables describe them (team, season, date). The fact grain here is one team in one match.

ETL

Extract, Transform, Load. Data is read from a messy feed, cleaned and standardised in Python, then loaded into the warehouse.

OLAP

Online Analytical Processing. SQL queries that slice, dice and roll up measures, for example goals by team, season and month.

Data mining

Finding hidden patterns. K-means groups similar teams into clusters, and Apriori finds rules between match events.

Live analytics

Real-time results, standings, squads and player profiles fetched from the internet for several top leagues.

Objectives

  • Design a star-schema data warehouse for football data.
  • Build an ETL pipeline that cleans a dirty match feed.
  • Answer analytical questions with OLAP queries.
  • Discover patterns with clustering and association rules.
  • Present live league data with club badges and player photos.

How to use this website

Use the menu on the left. ETL, OLAP and Data mining show the warehouse side of the project. Live scores, League table, Teams, Squad photos and Player search use the live feed, so they need an internet connection.

Technology: Python, SQLite, SQL, k-means, Apriori, HTML/CSS/JavaScript, TheSportsDB live data API.
